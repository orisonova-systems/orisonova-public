Shopify Restore Filenames

A local-first Chrome extension that generates deterministic safe filenames from uploaded-file rows in Shopify Admin order detail pages.

Core value

When the original filename is not visible in Shopify Admin, generate a safe operational filename from order number, SKU, property label, and extension.

Privacy

Shopify order data is processed locally in the browser and is not sent to an external server in the current version.
