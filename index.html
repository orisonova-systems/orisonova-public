Orisonova MicroTools

Orisonova MicroTools creates small, practical browser tools that reduce repetitive operational friction in existing web platforms.

Our tools are designed for local-first workflows: they help users extract, rename, copy, export, or restructure information that is already visible in their own browser, without sending platform data to an external server in the current version.

Current product

Shopify Restore Filenames

Shopify Restore Filenames is a Chrome extension for Shopify Admin order detail pages. It scans uploaded-file property rows and generates deterministic safe filenames for order-processing workflows.

When Shopify Admin or an upload provider does not show the customer's original filename, the extension generates an operational filename from available order information such as order number, SKU, property label, and file extension. 

1001_TEST-UP-001_Artwork-Upload.png

The extension can copy one filename, copy all generated filenames, or export TSV for spreadsheet-based workflows.

Data and privacy

Shopify order data is processed locally in the user's browser. The current version does not transmit Shopify order data, uploaded-file URLs, customer data, generated filenames, diagnostics, or scan results to Orisonova, Stripe, or any external server.

Payments, if made through a Starter link, are processed by Stripe outside the extension. The extension does not send Shopify order data to Stripe.
