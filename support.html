Current supported product

Shopify Restore Filenames

Shopify Restore Filenames is a Chrome extension for Shopify Admin order detail pages. It scans uploaded-file property rows and generates deterministic safe filenames for order-processing workflows. 

1001_TEST-UP-001_Artwork-Upload.png

The extension can copy one filename, copy all generated filenames, or export TSV for spreadsheet-based workflows.

Basic use

  1. Open a Shopify Admin order detail page.
  2. Open the Shopify Restore Filenames side panel.
  3. Click Refresh scan.
  4. Review the generated safe filename.
  5. Copy one filename, copy all filenames, or copy TSV.

What the extension does not promise

Shopify Restore Filenames does not promise perfect restoration of the customer's original filename.

If Shopify Admin or an upload provider exposes only an opaque object key, the extension generates a deterministic safe filename from available order information such as order number, SKU, property label, and file extension.

Common issue: no rows found

  1. Confirm you are on an individual Shopify order detail page, not a Products page or Orders list.
  2. Reload the Shopify Admin page.
  3. Open the side panel again.
  4. Click Refresh scan.
  5. Confirm the order contains an uploaded-file property row.

Common issue: generated filename ends in .bin

If a generated filename ends in .bin, the extension could not find a reliable file extension from the visible upload URL or Shopify Admin's link-confirmation text.

Open row diagnostics and copy diagnostics JSON before requesting support. Please redact sensitive values before sharing diagnostics from a real store.

Diagnostics

The extension includes Copy diagnostics JSON for troubleshooting. Diagnostics may include order URL, SKU, product title, uploaded-file URL, property label, generated filename, scanner status, and filename rule settings.

Diagnostics are copied only when the user explicitly clicks Copy diagnostics JSON. The current version does not send diagnostics to Orisonova automatically.
