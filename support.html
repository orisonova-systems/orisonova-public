Support — Shopify Restore Filenames

What this extension does

Shopify Restore Filenames scans Shopify Admin order detail pages for uploaded-file property rows and generates deterministic safe filenames for order processing workflows.

1001_TEST-UP-001_Artwork-Upload.png

Basic use

  1. Open a Shopify Admin order detail page.
  2. Open the Shopify Restore Filenames side panel.
  3. Click Refresh scan.
  4. Copy one filename, copy all filenames, or copy TSV.

Common issue: no rows found

  1. Confirm you are on an individual Shopify order detail page, not Products or Orders list.
  2. Reload the page.
  3. Click Refresh scan again.
  4. Confirm the order contains an uploaded-file property row.

Common issue: .bin extension

If a generated filename ends in .bin, the extension could not find a file extension from the visible upload URL. Open row diagnostics and copy diagnostics JSON before requesting support.

Diagnostics

The extension includes Copy diagnostics JSON for troubleshooting. Diagnostics may include order URL, SKU, product title, uploaded-file URL, property label, and generated filename. Redact sensitive values before sharing diagnostics from a real store.
