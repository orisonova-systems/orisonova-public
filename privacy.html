Privacy Policy — Orisonova MicroTools

Last updated: 2026-05-10

This privacy policy applies to Orisonova MicroTools products, including the current Chrome extension Shopify Restore Filenames.

Orisonova MicroTools creates small, practical browser tools that reduce repetitive operational friction in existing web platforms. The current product, Shopify Restore Filenames, helps users generate deterministic safe filenames from uploaded-file property rows on Shopify Admin order detail pages.

Core privacy position: the current version processes Shopify order-page information locally in the user's browser. It does not transmit Shopify order data, uploaded-file URLs, customer data, generated filenames, diagnostics, or scan results to Orisonova, Stripe, or any external server.

Data processed locally

When the user opens a Shopify Admin order detail page and runs a scan, Shopify Restore Filenames may read visible page content and related link-confirmation text in the user's browser.

The extension may process the following information locally:

  • Shopify Admin order page URL
  • Order number
  • Product title
  • SKU
  • Uploaded-file property label
  • Visible upload link text
  • Destination URL shown by Shopify Admin's link-confirmation modal
  • URL basename and file extension, when available
  • Generated safe filename
  • Diagnostic information used for troubleshooting

This processing is performed locally in the browser to generate filenames, copy filenames, export TSV, and create diagnostics when the user explicitly requests them.

Data stored locally

The extension may store limited information in Chrome local storage on the user's device, including:

  • The latest scan result
  • Filename naming rules selected by the user
  • Local monthly copy-action count used for the free-preview meter
  • Local extension settings

This information is stored locally in the browser. The current version does not sync this data to Orisonova or to any external server.

External transmission

The current version does not transmit Shopify order data, uploaded-file URLs, product titles, SKUs, customer data, diagnostics, generated filenames, scan results, or local usage counts to Orisonova, Stripe, or any external server.

The extension does not use analytics, remote tracking, or external telemetry in the current version.

Diagnostics

The extension can create diagnostics JSON for troubleshooting. Diagnostics are copied only when the user explicitly clicks Copy diagnostics JSON.

Diagnostics may include Shopify Admin page URL, order number, SKU, product title, uploaded-file URL, property label, generated filename, scanner status, and rule settings.

Users should not share diagnostics from a real store unless sensitive information has been removed.

Payments and licensing

Orisonova MicroTools may offer a Starter plan for Shopify Restore Filenames. The current Starter plan is planned at ¥1,200/year.

Payments, if made through a Starter payment link, are handled by Stripe Payment Links outside the extension. The extension does not send Shopify order data to Stripe.

Stripe may collect payment-related information directly from the customer according to Stripe's own terms and privacy policy. Orisonova does not receive the customer's card number from Stripe.

The current extension version uses a local soft quota and does not yet include server-side license verification or hard blocking.

User control

Users may uninstall the extension at any time through Chrome's extension management page.

Users may also clear local extension data through Chrome browser settings. Clearing local data may reset locally stored scan results, filename rules, and local usage counters.

Children

Orisonova MicroTools products are intended for business and operational workflows. They are not directed to children.

Changes to this policy

This privacy policy may be updated as Orisonova MicroTools adds products, paid plans, licensing, or additional features. Material changes will be reflected on this page.
