Privacy Policy — Shopify Restore Filenames

Last updated: 2026-05-06

Shopify Restore Filenames is a local-first Chrome extension for Shopify Admin order detail pages. It helps users generate deterministic safe filenames from uploaded-file property rows, then copy filenames or export TSV.

Data processed locally

When the user opens a Shopify Admin order detail page, the extension may read visible page content and related link-confirmation text in the user’s browser, including order number, product title, SKU, uploaded-file property label, visible upload link text, destination URL shown by Shopify Admin’s link confirmation modal, and generated safe filenames.

This processing is performed locally in the browser to generate filenames and diagnostics.

Data stored locally

The extension may store the latest scan result, filename naming rules, and local monthly copy-action count in Chrome local storage.

External transmission

The current version does not transmit Shopify order data, uploaded-file URLs, product titles, SKUs, customer data, diagnostics, generated filenames, or scan results to any external server.

Diagnostics

The extension can create diagnostics JSON for troubleshooting. Diagnostics are copied only when the user explicitly clicks Copy diagnostics JSON. Diagnostics may include Shopify Admin page URL, order number, SKU, product title, upload URL, property label, and generated filename. Users should not share diagnostics from real stores unless sensitive information has been removed.

Payments and licensing

The current version does not include live payment processing or license verification. It includes only a local soft free-preview usage meter and planned Starter messaging. If a future version adds paid licensing, the extension should transmit only the minimum information required for license verification, such as a license key or account token. Shopify order data should remain local and should not be sent for payment or licensing.

Data sale and advertising

The extension does not sell user data. It does not use Shopify order data for advertising or tracking.
